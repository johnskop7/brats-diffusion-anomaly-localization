# References

The project is primarily inspired by the paper:

**What is Healthy? Generative Counterfactual Diffusion for Lesion Localization**

The method motivates the use of a generative diffusion model to estimate a healthy counterfactual for an anomalous medical image and derive an anomaly map from the difference between the observed image and its healthy reconstruction.

A BibTeX entry is provided in `references.bib`.
