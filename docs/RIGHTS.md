# Rights and attribution

This repository contains coursework produced for a university Pattern Recognition project.

The project is based on and inspired by the research paper *What is Healthy? Generative Counterfactual Diffusion for Lesion Localization*. The original paper, BraTS dataset, third-party libraries, and any externally sourced figures remain subject to their respective authors' licenses and terms.

The repository does not claim ownership of the BraTS dataset and does not redistribute the dataset itself.

Course material, report content, presentation material, and code authored by the student group are included for educational and portfolio purposes.
